# Customer Shopping Behavior Analysis

## Project Overview
This end-to-end data analytics project analyzes customer shopping behavior using transactional data.
The goal is to uncover insights related to customer segments, purchase patterns, discount usage,
and product preferences to support business decision-making.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- SQL (Data analysis & business queries)
- Power BI (Interactive dashboard)
- Excel (Initial data understanding)

## Dataset Summary
- Rows: 3,900
- Columns: 18
- Key features include customer demographics, purchase details, discounts, ratings, and shipping type.

## Key Analysis Performed
- Data cleaning and preprocessing using Python
- Missing value imputation using median by category
- Feature engineering (age groups, purchase frequency)
- SQL-based business analysis
- Power BI dashboard creation
- Business insights and recommendations

## Key Insights
- Male customers generate higher total revenue
- Express shipping users tend to spend more
- High-rated products show strong customer satisfaction
- Non-subscribers contribute higher total revenue due to volume

## Business Recommendations
- Apply targeted discounts instead of blanket offers
- Strengthen loyalty programs for repeat customers
- Promote high-rated products
- Improve subscription value propositions
- Use data-driven strategies for inventory and marketing
